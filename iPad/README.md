# SimPleview 笔记（iPadOS）

独立的 iPad 工程，最低 iPadOS 18。安装步骤见 [主 README 的 iPadOS 安装教程](../README.md#ipados)，包括 Xcode 工程选择、签名、开发者模式和真机运行。macOS 安装包不能用于 iPad。

## 与 Mac 的边界

所有 iPad 源码、资源、配置都在本目录；不引用或修改根目录的 macOS target。Bundle ID、钥匙串和偏好设置独立。离线公式渲染资源也独立打包，保留第三方许可证。

## 使用

- 新建空白、横线、方格、点阵 PDF 笔记本；用文件夹整理，支持重命名、移动、导入 PDF 副本。
- 书架右上角“打开文件”可从系统“文件”选择本机或 iCloud Drive 的原 PDF，直接阅读、标注并保存回原位置，不复制到笔记目录。“导入 PDF 副本”仍保留在添加菜单中。跨设备使用时，两端选择同一份 iCloud 文件，并在切换设备前等待文件同步完成；不自动合并同时编辑的冲突版本。
- 默认保存在“我的 iPad / SimPleview 笔记”对应的应用文档目录。书架的“选择笔记目录”也可选择文件提供商允许访问的 iCloud Drive 文件夹。
- PDF 阅读支持缩放、页面缩略图、原有目录、文字搜索、插页、复制、删除、排序、文字标注和全部标注显隐。
- 书写采用 PencilKit，默认仅 Apple Pencil；“更多”中可以允许手指。首版提供等宽笔、半透明等宽笔、整笔橡皮、套索及笔迹撤销/重做。
- AI 设置可添加多个兼容 Chat Completions 的 API，每个 API 独立密钥和模型列表。按精确模型 ID 请求；服务端返回不同型号时停止，不自动替换。
- 对话按完整句子更新，可暂停。当前页/全文读取仅在主动点击后发送页面图像，每批最多两页且串行处理。保持对话页打开时可继续未完成的 PDF 批次；关闭对话页或重启应用后，历史回答仍保留，但批次续读游标不保留。

## 文件与笔迹

笔迹写入 PDF 的标准 Ink 标注，并在每页附一份原生编辑数据。普通阅读器可显示标准笔迹，iPad 重新打开可恢复原生编辑；现有 Mac 版使用其原有高清矢量绘制。近共线采样点仅在 PDF 显示副本中简化，原生编辑数据不删减。重复保存替换原有数据，不叠加历次笔迹。

“导出可编辑 PDF”保留标准标注和原生编辑附件；“导出通用矢量 PDF”把笔迹直接写成页面矢量绘图指令，可绕开其他阅读器的标注位图缓存。通用副本不再提供逐笔编辑，也不保留原文件的交互表单、链接及目录结构；原笔记本不受影响。扫描 PDF 的原有图片不会因此变成矢量。

自动保存按修改版本串行执行；检测到外部替换时拒绝覆盖，并保留已生成的本地恢复 PDF，可从书架“恢复的笔记”找到。“已保存”只表示文件写入完成，不代表 iCloud 已完成同步。写完后应等待“已保存”再退出；系统突然终止应用仍可能丢失最近尚未保存的输入。

外部软件改动过的笔迹，仅在标准几何仍与原生附件一致时恢复 PencilKit 编辑；不一致时保留外部修改，不复活旧笔迹。第三方软件可能删除私有编辑附件，此时标准 PDF 笔迹仍可阅读，但不能恢复原生笔迹编辑。

## 验证范围

以 Xcode 编译、模拟器原生画布集成检查、PDF 数据往返和未修改的 Mac 绘制回归为主；不调用视觉模型，也不发送真实 API 请求。已在连接的 iPad 真机验证原生工具连续切换、自动保存及笔迹重开。当前 iOS 27 Beta 模拟器的标准 Ink 序列化未通过校验时会停止覆盖原文件，不采用模拟器专用的原始数组写入。实际 Apple Pencil 延迟、掌托防误触，以及具体文件提供商的跨设备同步仍需真机验收。压力笔和纹理笔尚未开放，避免把不等价的外观冒充无损矢量。

调试脚本、测试样本、DerivedData 和编译产物不属于本目录的交付文件。
